03 / PROTECTION LAYERS

Security, by
architecture.

A view of the security mechanisms implemented in this project.

01 / CONFIDENTIALITY

AES-256-GCM

Authenticated encryption protects file contents. Each chunk uses its own random nonce and authenticated metadata.

IMPLEMENTED IN CODE
02 / INTEGRITY

HMAC-SHA256

A separate secret key produces a signature for the encrypted file. The signature is checked before decryption.

IMPLEMENTED IN CODE
03 / ACCOUNT

Password hashing

Passwords are stored as Werkzeug password hashes, not as plain text.

IMPLEMENTED IN CODE
04 / REQUESTS

CSRF protection

Flask-WTF CSRF tokens protect state-changing form submissions.

IMPLEMENTED IN CODE
05 / TRANSPORT

HTTPS / TLS

HTTPS must be configured at deployment using a trusted TLS endpoint. Local development is not automatically HTTPS.

DEPLOYMENT REQUIRED
06 / ACCESS

File ownership

Download queries include both the file ID and the signed-in user's ID.

IMPLEMENTED IN CODE
